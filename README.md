# GIPAssist — Панель ГИП

Портативное приложение для Windows. При успешной сборке скачайте архив **GIP-Panel-Windows** во вкладке [Actions](../../actions), открыв последний успешный запуск «Build Windows portable».

После запуска EXE создаёт рядом папку `GIP-Panel-Data`. Для переноса на другой компьютер копируйте её вместе с EXE. Делайте резервные копии данных.

Для самостоятельной сборки установите Node.js LTS и выполните `npm ci` и `npm run build:win`. Готовый EXE появится в папке `dist`.

Программа не подписана цифровой подписью и требует проверки на Windows. Роли локальные и не обеспечивают защиту от других пользователей компьютера.
